# Judgment Kernel

**Judgment Kernel** is a structural architecture for accountable decision-making in AI systems.

---

## Core Definition

> A Judgment Kernel is a first-class architectural component that authorizes decisions under explicit normative constraints and binds responsibility at the moment of judgment.

---

## Architecture Principle

**Inference–Judgment Separation**

Inference produces recommendations.
Judgment authorizes decisions.
Decision executes outcomes.

---

## Concept Structure

Governance Primitive
→ Judgment Kernel
→ Judgment Layer
→ Responsibility Anchor
→ Accountability Drift
